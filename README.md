# Perfil Profissional — DevOps

## Sobre o projeto
Projeto acadêmico desenvolvido durante a disciplina de
DevOps da Universidade Veiga de Almeida (UVA).

O objetivo foi praticar conceitos de controle de versão,
colaboração e integração contínua utilizando Git,
GitHub e GitHub Actions.

## Tecnologias utilizadas
- HTML5
- CSS3
- Git
- GitHub
- GitHub Actions
- YAML

## Funcionalidades
- Página de apresentação profissional.
- Estilização com CSS.
- Controle de versão com Git.
- Desenvolvimento utilizando branches.
- Integração de alterações por Pull Request.
- Pipeline automatizado com GitHub Actions.

## Integração contínua
Foi desenvolvido um workflow para verificar
automaticamente a existência dos arquivos HTML e CSS.

Durante a atividade, uma falha foi introduzida
propositalmente para testar o pipeline.

Após identificar o erro nos logs, o problema foi
corrigido e o workflow executado com sucesso.

## Aprendizados
- Criação e gerenciamento de branches.
- Commits utilizando Conventional Commits.
- Criação e integração de Pull Requests.
- Configuração de workflows YAML.
- Análise de logs.
- Correção de falhas em pipelines.
- Geração de artefatos.
